## 1. 项目概述

### 1.1 项目信息
- **项目名称**: SiWu-IoT-Views Frontend
- **版本**: 3.8.8
- **基于**: Vue 2.6.12 + Element UI 2.15.14
- **项目类型**: 单页应用（SPA）
- **构建工具**: Vue CLI 4.4.6

### 1.2 项目特点
- 基于Vue 2.x的现代化前端框架
- 集成数据大屏设计器（data-room-ui）
- 支持多种图表库（Echarts、G2Plot）
- 完善的权限管理体系
- 响应式布局设计

## 6. 核心功能模块

### 6.1 路由管理

#### 6.1.1 路由配置
- **静态路由**: 登录、404等无需权限的页面
- **动态路由**: 根据用户权限动态生成

#### 6.1.2 路由守卫
```javascript
// permission.js
router.beforeEach((to, from, next) => {
  // 检查Token
  // 获取用户信息
  // 生成动态路由
  // 权限验证
})
```

#### 6.1.3 动态路由生成
- 从后端获取菜单数据
- 转换为Vue Router路由配置
- 动态添加到路由表

### 6.2 状态管理

#### 6.2.1 用户模块（user.js）
- `state`: token、用户信息、角色、权限
- `actions`: Login、GetInfo、LogOut
- `mutations`: SET_TOKEN、SET_ROLES等

#### 6.2.2 权限模块（permission.js）
- `state`: 路由列表
- `actions`: GenerateRoutes（生成路由）

#### 6.2.3 大屏模块（bigScreen）
- 集成自`data-room-ui`的Store
- 管理大屏设计状态

### 6.3 权限控制

#### 6.3.1 路由权限
- 通过路由守卫控制页面访问
- 根据用户角色动态生成路由

#### 6.3.2 按钮权限
```vue
<!-- 使用指令控制按钮显示 -->
<el-button v-hasPermi="['system:user:add']">新增</el-button>
```

#### 6.3.3 指令定义
```javascript
// directive/permission/hasPermi.js
Vue.directive('hasPermi', {
  inserted(el, binding) {
    // 检查权限
  }
})
```

### 6.4 HTTP请求

#### 6.4.1 Axios封装
- 请求拦截器: 添加Token、防重复提交
- 响应拦截器: 统一错误处理、Token过期处理

#### 6.4.2 请求配置
```javascript
// utils/request.js
const service = axios.create({
  baseURL: process.env.VUE_APP_BASE_API,
  timeout: 10000
})
```

### 6.5 大屏设计器集成

#### 6.5.1 注册配置
```javascript
// main.js
import { registerConfig } from '@gcpaas/data-room-ui'

registerConfig({
  routers: {
    designUrl: '/bigscreen/design',
    previewUrl: '/bigscreen/preview',
    // ...
  },
  httpConfigs: {
    baseURL: process.env.VUE_APP_BASE_API,
    headers: {
      AuthToken: 'Bearer ' + getToken()
    }
  },
  customPlots: customPlots,
  customDatasetComponents: customDatasetComponents,
  remoteComponents: remoteComponents
}, router)
```

#### 6.5.2 大屏设计流程
1. 进入设计页面 → `BigScreenDesign`组件
2. 加载大屏配置 → 从后端获取JSON配置
3. 渲染画布 → `Render`组件渲染组件
4. 编辑组件 → 右侧设置面板
5. 保存配置 → 提交到后端

## 8. 扩展开发指南

### 8.1 新增页面

1. **创建Vue组件**
   ```vue
   <!-- views/your-module/index.vue -->
   <template>
     <div>Your Page</div>
   </template>
   <script>
   export default {
     name: 'YourPage'
   }
   </script>
   ```

2. **添加路由**
   ```javascript
   // router/index.js
   {
     path: '/your-path',
     component: Layout,
     children: [{
       path: 'index',
       component: () => import('@/views/your-module/index'),
       name: 'YourPage',
       meta: { title: '页面标题', icon: 'icon' }
     }]
   }
   ```

3. **添加菜单**（后端菜单管理）

### 8.2 新增API接口

1. **创建API文件**
   ```javascript
   // api/your-module.js
   import request from '@/utils/request'
   
   export function getList(params) {
     return request({
       url: '/your-api/list',
       method: 'get',
       params
     })
   }
   ```

2. **在组件中使用**
   ```javascript
   import { getList } from '@/api/your-module'
   
   export default {
     methods: {
       async fetchData() {
         const res = await getList()
         // 处理数据
       }
     }
   }
   ```

### 8.3 新增公共组件

1. **创建组件**
   ```vue
   <!-- components/YourComponent/index.vue -->
   <template>
     <div>Your Component</div>
   </template>
   <script>
   export default {
     name: 'YourComponent',
     props: {
       // props定义
     }
   }
   </script>
   ```

2. **全局注册**（可选）
   ```javascript
   // main.js
   import YourComponent from '@/components/YourComponent'
   Vue.component('YourComponent', YourComponent)
   ```

### 8.4 新增大屏组件

1. **创建组件文件**
   ```
   packages/BasicComponents/YourComponent/
   ├── index.vue          # 组件模板
   └── config.js          # 组件配置
   ```

2. **组件配置**
   ```javascript
   // config.js
   export default {
     type: 'your-component',
     name: '你的组件',
     icon: 'icon-name',
     // 其他配置
   }
   ```

3. **注册组件**
   ```javascript
   // packages/BasicComponents/exports.js
   import YourComponent from './YourComponent'
   export default {
     YourComponent
   }
   ```

### 8.5 新增图表组件

#### 8.5.1 Echarts图表
1. 在`packages/Echarts/`下创建图表组件
2. 实现数据获取和渲染逻辑
3. 在`packages/Echarts/exports.js`中注册

#### 8.5.2 G2Plot图表
1. 在`packages/G2Plots/`下创建图表组件
2. 实现G2Plot配置
3. 在`packages/G2Plots/exports.js`中注册

## 9. 开发规范

### 9.1 代码规范
- 遵循Vue官方风格指南
- 使用ESLint进行代码检查
- 组件名使用PascalCase
- 文件名使用kebab-case

### 9.2 组件规范
- 单文件组件（.vue）
- Props定义必须包含类型
- 事件命名使用kebab-case
- 组件必须有name属性

### 9.3 命名规范
- 变量/函数: camelCase
- 常量: UPPER_SNAKE_CASE
- 组件: PascalCase
- 文件: kebab-case

### 9.4 注释规范
- 组件必须有说明注释
- 复杂逻辑必须添加注释
- API接口必须有注释

## 12. 常见问题

### 12.1 路由跳转404
- 检查路由配置是否正确
- 检查动态路由是否已生成

### 12.2 权限不生效
- 检查用户角色权限配置
- 检查`v-hasPermi`指令是否正确

### 12.3 大屏组件不显示
- 检查组件是否已注册
- 检查组件配置是否正确
- 查看浏览器控制台错误

### 12.4 接口请求失败
- 检查后端服务是否启动
- 检查代理配置是否正确
- 检查Token是否有效
