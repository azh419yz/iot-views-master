## 1. 项目概述

### 1.1 项目信息
- **项目名称**: SiWu-IoT-Views
- **版本**: 3.8.8
- **基于**: RuoYi-Vue 3.8.8 和 Dataroom 2.0.0
- **项目类型**: 物联网可视化平台
- **开发语言**: Java 17
- **构建工具**: Maven

### 1.2 项目特点
- 基于Spring Boot的多模块Maven项目
- 采用前后端分离架构
- 集成数据大屏设计功能
- 支持多种数据源接入
- 完善的权限管理体系

## 4. 模块架构

### 4.1 swiot-admin（主应用模块）

**职责**: Web服务入口，包含启动类和控制器

**主要类**:
- `SiWuApplication.java`: Spring Boot启动类
- `SiWuServletInitializer.java`: Web容器部署支持

**关键配置**:
- 扫描包路径: `com.swiot`, `com.gccloud`
- 排除自动配置: `DataSourceAutoConfiguration`（使用自定义数据源）

**主要功能**:
- 系统监控（在线用户、服务器监控、缓存监控等）
- 系统管理（用户、角色、菜单、部门等）
- 工具类（代码生成、系统接口等）

**关键文件**:
```
swiot-admin/
├── src/main/java/com/swiot/
│   ├── SiWuApplication.java          # 启动类
│   ├── web/controller/                # 控制器

### 4.2 swiot-framework（框架核心模块）

**职责**: 提供框架级功能，包括安全、配置、拦截器等

**主要包结构**:
```
swiot-framework/
├── aspectj/              # AOP切面
│   ├── DataScopeAspect.java          # 数据权限切面
│   ├── DataSourceAspect.java         # 数据源切换切面
│   ├── LogAspect.java                # 日志切面
│   └── RateLimiterAspect.java        # 限流切面
├── config/               # 配置类
│   ├── SecurityConfig.java           # Spring Security配置
│   ├── MybatisPlusConfig.java        # MyBatis Plus配置
│   ├── DruidConfig.java               # Druid数据源配置
│   ├── RedisConfig.java               # Redis配置
│   └── ...
├── datasource/           # 数据源管理
│   ├── DynamicDataSource.java        # 动态数据源
│   └── DynamicDataSourceContextHolder.java
├── security/             # 安全相关
│   ├── filter/JwtAuthenticationTokenFilter.java  # JWT过滤器
│   └── handle/                       # 认证处理
├── web/                  # Web相关
│   ├── service/                       # 服务类
│   │   ├── TokenService.java         # Token服务
│   │   ├── SysLoginService.java       # 登录服务
│   │   └── UserDetailsServiceImpl.java # 用户详情服务
│   └── exception/                     # 异常处理
└── interceptor/          # 拦截器

**核心功能**:

1. **安全认证体系**
   - JWT Token认证
   - Spring Security集成
   - 密码加密（BCrypt）
   - 验证码支持

2. **数据源管理**
   - 动态数据源切换
   - 主从数据源支持
   - Druid连接池监控

3. **AOP切面**
   - 数据权限控制（`@DataScope`）
   - 操作日志记录（`@Log`）
   - 接口限流（`@RateLimiter`）
   - 防重复提交（`@RepeatSubmit`）

## 5. 核心功能模块

### 5.1 安全认证体系

#### 5.1.1 JWT认证流程
1. 用户登录 → `SysLoginService.login()`
2. 验证用户名密码 → `UserDetailsServiceImpl.loadUserByUsername()`
3. 生成Token → `TokenService.createToken()`
4. Token存储到Redis
5. 请求携带Token → `JwtAuthenticationTokenFilter` 验证

#### 5.1.2 权限控制
- **菜单权限**: 通过`@PreAuthorize`注解控制
- **数据权限**: 通过`@DataScope`注解控制
- **按钮权限**: 前端通过`v-hasPermi`指令控制

#### 5.1.3 关键类说明
- `SecurityConfig`: Spring Security配置
- `JwtAuthenticationTokenFilter`: JWT认证过滤器
- `TokenService`: Token生成和验证服务
- `UserDetailsServiceImpl`: 用户认证服务

### 5.2 数据源管理

#### 5.2.1 动态数据源
- 支持主从数据源切换
- 通过`@DataSource`注解切换数据源
- 默认使用主数据源

#### 5.2.2 数据源配置
```java
// 主数据源
@Bean
@ConfigurationProperties("spring.datasource.druid.master")
public DataSource masterDataSource()

// 从数据源（可选）
@Bean
@ConditionalOnProperty(prefix = "spring.datasource.druid.slave", name = "enabled", havingValue = "true")
public DataSource slaveDataSource()
```

### 5.3 权限管理

#### 5.3.1 菜单权限
- 基于Spring Security的`@PreAuthorize`注解
- 权限标识格式: `system:user:list`

#### 5.3.2 数据权限
- 通过`@DataScope`注解实现
- 支持按部门、按用户等维度控制数据访问

### 5.4 大屏管理

#### 5.4.1 大屏页面
- 大屏配置以JSON格式存储
- 支持大屏分组（树形结构）
- 支持大屏预览

#### 5.4.2 图表数据
- 通过`ChartDataController`提供图表数据接口
- 支持多种数据源（数据集、HTTP接口等）
- 支持数据刷新

### 5.5 代码生成器

#### 5.5.1 使用流程
1. 在代码生成页面选择数据表
2. 配置生成选项
3. 生成代码并下载
4. 将代码复制到对应模块

#### 5.5.2 生成内容
- 后端: Entity、Mapper、Service、Controller
- 前端: Vue页面、API接口

## 8. 扩展开发指南

### 8.1 新增业务模块

1. **创建实体类**
   ```java
   @Data
   @TableName("your_table")
   public class YourEntity extends BaseEntity {
       // 字段定义
   }
   ```

2. **创建Mapper接口**
   ```java
   @Mapper
   public interface YourMapper extends BaseMapper<YourEntity> {
       // 自定义方法
   }
   ```

3. **创建Service接口和实现**
   ```java
   public interface IYourService {
       // 方法定义
   }
   
   @Service
   public class YourServiceImpl implements IYourService {
       // 实现
   }
   ```

4. **创建Controller**
   ```java
   @RestController
   @RequestMapping("/your/path")
   public class YourController extends BaseController {
       // 接口定义
   }
   ```

### 8.2 新增数据源

1. 在`application-dev.yml`中配置数据源
2. 在`DruidConfig`中添加数据源Bean
3. 使用`@DataSource`注解切换数据源

### 8.3 新增权限控制

1. 在菜单管理中添加菜单和权限标识
2. 在Controller方法上添加`@PreAuthorize`注解
3. 前端使用`v-hasPermi`指令控制按钮显示

### 8.4 集成第三方服务

1. 在对应模块的`pom.xml`中添加依赖
2. 创建配置类
3. 在`application.yml`中添加配置项

### 8.5 自定义异常处理

1. 继承`ServiceException`创建自定义异常
2. 在`GlobalExceptionHandler`中添加异常处理逻辑

### 8.6 扩展大屏组件

1. 在`swiot-dataroom`模块的`chart/components/`下创建组件类
2. 实现图表数据获取逻辑
3. 前端在`packages/`目录下添加对应组件

## 9. 开发规范

### 9.1 代码规范
- 遵循阿里巴巴Java开发手册
- 使用统一的代码格式化配置
- 类和方法必须有注释

### 9.2 命名规范
- 类名: 大驼峰（PascalCase）
- 方法名: 小驼峰（camelCase）
- 常量: 全大写下划线分隔
- 包名: 全小写

### 9.3 接口规范
- 统一使用`AjaxResult`作为返回类型
- 使用RESTful风格
- 接口必须有Swagger注解

## 11. 常见问题

### 11.1 数据源切换不生效
- 检查`@DataSource`注解是否正确
- 检查数据源配置是否正确

### 11.2 Token过期
- 检查Token有效期配置
- 检查Redis连接是否正常

### 11.3 权限不生效
- 检查用户角色权限配置
- 检查`@PreAuthorize`注解是否正确
